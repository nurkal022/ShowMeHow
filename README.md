# ShowMeHow

Генератор интерактивных научных симуляций для преподавателей. Опишите явление —
получите интерактивную визуализацию (2D/3D) для показа на занятии.

## Запуск

```bash
npm install
npx playwright install chromium
npm run dev
```

Откройте http://localhost:3000 → Настройки → добавьте провайдера
(любой OpenAI-совместимый: OpenAI, OpenRouter, Ollama...). Укажите модель генерации
и vision-модель (для критика и судьи качества).

## Как это работает

Пайплайн: план симуляции → 1-3 кандидата → headless-проверка (Playwright) с
автопочинкой → физик-критик по скриншотам → судья по рубрике → доводка до порога
качества. Режимы: быстрый / стандарт / максимум.

Проверка кандидата — не только «нет ошибок в консоли»: по живой странице гоняются
поведенческие пробы (идёт ли анимация, останавливает ли её пауза, возвращает ли
«Сброс» начальное состояние, влияют ли слайдеры, нет ли NaN/Infinity в величинах,
не лезет ли артефакт за пределы whitelist CDN). Провалы проб уходят в фиксер
текстом. В промпт генератора кладётся ближайшая по теме эталонная демка из
`demos/` — как образец требуемого уровня.

Результат — самодостаточный HTML-файл: работает в библиотеке, в полноэкранном
режиме презентации и как экспортированный файл без сервера.

### Задания и прогресс

Генерация — это задание (job), а не разовый запрос: сервер ведёт журнал событий
пайплайна (план готов, кандидат такой-то, вердикт критика/судьи, круг доводки...),
а клиент хранит id активного задания в браузере. Если случайно перезагрузить
страницу посреди генерации — прогресс восстанавливается по журналу, а не теряется.
Пока задание выполняется, можно нажать «✕ Отменить»: пайплайн остановится на
ближайшей безопасной точке, и в библиотеку ничего не сохранится.

Рядом с режимом качества есть селектор «Кандидатов» (1-5) — сколько вариантов
симуляции сгенерировать параллельно перед тем, как судья выберет лучший
(по умолчанию зависит от режима: быстрый — 1, стандарт — 2, максимум — 3).

## Демо-библиотека

В комплекте — 10 готовых симуляций (диффузия, маятник, осмос, преломление,
идеальный газ, конвекция, интерференция, электростатическое поле, орбиты
Кеплера, двигатель внутреннего сгорания и др.), не требующих провайдера.

Две из них — `engine` (четырёхтактный ДВС) и `pendulum` (математический маятник) —
помечены эталонами SimUI 2.0 (`"exemplar": true` в `meta.json`): они целиком
построены на примитивах кита (баннер такта, показания, живые графики, формулы с
подставленными числами, пресеты, `SimUI.expose`) и не рисуют собственных панелей.
Именно их пайплайн подставляет генератору как образец.

Установить их можно двумя способами:

- в пустой библиотеке (`/library`) нажать «Установить 10 примеров»;
- из терминала: `npm run seed`.

Уже установленные демки при повторном запуске пропускаются.

## Команды

- `npm test` — юнит/интеграционные тесты
- `npm run test:e2e` — e2e с мок-провайдером
- `npm run eval` — прогон эталонных промптов с оценкой качества (нужен настроенный провайдер)
- `npm run seed` — установить 10 готовых демо-симуляций в библиотеку
