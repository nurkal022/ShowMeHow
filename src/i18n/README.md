# Переводы интерфейса (ru / kk / en)

Русский — исходный язык и запасной. Язык пользователя лежит в cookie `tesseract-lang`,
переключатель — `src/components/LanguageSwitcher.tsx` (меню аккаунта, шапка гостя).

## Как перевести компонент

1. Словарь области — `src/i18n/messages/<область>.ts`, три языка в одном файле:
   ```ts
   import { defineMessages } from '../core';
   export const teach = defineMessages({
     ru: { title: 'Курсы', students: '{n, plural, one {# ученик} few {# ученика} many {# учеников} other {# ученика}}' },
     kk: { title: 'Курстар', students: '{n, plural, other {# оқушы}}' },
     en: { title: 'Courses', students: '{n, plural, one {# student} other {# students}}' },
   });
   ```
   TypeScript требует те же ключи в kk и en. Большую область делите на несколько файлов
   (`teach-course.ts`, `teach-review.ts`), чтобы словари оставались читаемыми.
2. Клиентский компонент: `const t = useT(teach);` → `t('title')`, `t('students', { n })`.
   Даты: `const f = useFormat(); f.date(iso)` вместо `toLocaleDateString('ru-RU')`.
3. Серверный компонент и `generateMetadata`: `const t = await getT(teach);` (`@/i18n/server`),
   язык — `await getLocale()`, даты — `formatDate(d, locale)` из `@/i18n/core`.
4. Роут API с `req`: язык — `localeFromRequest(req)` (`@/i18n/config`), синхронно.
5. Общие слова (Сохранить, Отмена, Удалить…) — `common` из `@/i18n/messages/common`.

## Сообщения сервера

Библиотеки и роуты по-прежнему пишут ошибки **по-русски** (логи, тесты, воркер без запроса).
Интерфейс переводит их по каталогу: добавьте каждое такое сообщение в свой файл
`src/i18n/catalog/<область>.ts` — `{ ru: 'Проект не найден.', kk: '…', en: '…' }`. Изменяемую часть
пишите как `{n}`: `{ ru: 'Название — не длиннее {n} символов.', kk: 'Атауы {n} таңбадан аспауы керек.', en: 'Title must be at most {n} characters.' }`.
На клиенте, где показывается `error` из ответа сервера, оборачивайте: `useFormat().message(text)`.

## ИИ отвечает на языке пользователя

Если роут зовёт модель и результат читает пользователь (объяснения, черновики, отчёты),
передайте язык (`localeFromRequest(req)`) в функцию и добавьте в промпт «Отвечай на казахском/английском/русском языке».
Сами промпты для модели не переводите — достаточно указания языка ответа.

## Чего не делать

- Не переводить: комментарии, логи, тексты для модели (промпты), значения в базе, ключи, адреса, названия CSS-классов.
- Не менять поведение и разметку сверх замены текста. Не трогать чужие файлы (см. поручение).
- Не ломать тесты: русский — язык по умолчанию, поэтому тесты с русскими строками должны проходить как раньше.
- Не склеивать фразы из кусков («Удалить » + name) — пишите целую фразу с `{name}`: порядок слов в казахском другой.
