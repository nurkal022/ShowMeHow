# Telegram-бот сообщества

Бот @TesseractHubBot выдаёт доступ к платформе и ведёт группу «Tesseract — Сообщество» (форум с темами).
Код: `src/lib/telegram/`, страница привязки `/tg/claim`, API `/api/tg/*`, `/api/me/telegram`, `/api/admin/community`.
Админка: **Платформа → Сообщество** (`/admin/community`).

## Переменные (`.env.local`)

| Переменная | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather. Нет токена — бот не запускается, сайт работает как раньше |
| `TELEGRAM_SITE_URL` | адрес сайта для ссылок из бота, например `https://tesseract.kz`. По умолчанию `http://localhost:3000` |
| `TELEGRAM_BOT_EMBEDDED` | `0` — не запускать бота внутри веб-процесса (тогда нужна служба `teseract-bot`) |
| `TELEGRAM_GROUP_ID` | необязательно: группа запоминается сама по команде `/setup` |

## Как запускается

Long polling, без webhook: webhook требует HTTPS. По умолчанию бот работает **внутри веб-процесса**
(`src/instrumentation.ts`), отдельная служба не нужна. Отдельным процессом: `npm run bot`
или `ops/systemd/teseract-bot.service` (тогда в вебе `TELEGRAM_BOT_EMBEDDED=0`).

**Один токен — один процесс.** Второй получит от Telegram 409 и будет ждать. Для локальной разработки
заводите отдельного тестового бота и тестовую группу, если боевой уже крутится на сервере.

## Первичная настройка группы

1. Группа с включёнными «Темами», бот — администратор (управление темами, удаление, блокировка, приглашения).
2. В группе от имени её админа: `/setup`. Бот создаёт темы, закрывает «Анонсы» и «Правила», публикует
   правила и приветствие, урезает права участников и делает ссылку-заявку. Повторный `/setup` безопасен.

## Путь человека

`/start` в боте → язык → роль → одноразовая ссылка (15 мин) → `/tg/claim`: новый аккаунт или привязка
существующего → бот одобряет заявку в группу и присылает темы. С сайта: профиль → «Подключить Telegram».

Вход в группу без привязанного аккаунта (по старой ссылке, добавил участник) — бот исключает и зовёт в `/start`.
Блокировка аккаунта на платформе исключает из группы. Отвязка (профиль или админка) — тоже.

## Команды

- Личка: `/start`, `/login` (вход без пароля, не для админа платформы), `/group`, `/topics`, `/share ссылка комментарий`, `/me`, `/lang`, `/help`.
- Админу платформы в личке: `/stats`, `/announce текст`.
- Админу группы в группе: `/setup`; ответом на сообщение — `/ban`, `/mute [часы]`, `/unmute`.
